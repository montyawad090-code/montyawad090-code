### What I'm building

**[sunnah-bot](https://github.com/montyawad090-code/sunnah-bot)** — the Python
Telegram bot behind Sunnah Companion. Prayer-time, adhkar and daily reminders
that arrive with nothing open. One third-party dependency. Idempotent dispatch,
so a reminder fires once or not at all, never twice. Running unattended since
June 2026.

**Sunnah Companion** — installable PWA. Prayer times, daily checklist, Qur'an
reader, Qibla compass, streak tracking. Vanilla HTML, CSS and JavaScript,
offline-capable, no build step.

### How I work

- Work to the constraint, prove it, and be able to defend the reasoning afterwards.
- Cache against the thing that actually changes — caching prayer times against
  the date rather than a TTL cut external calls to one a day.
- Few dependencies. Less that can break silently.
- Test on a real phone. That is where the bugs were.
- Write down what something *cannot* do rather than dressing the limits up as features.
